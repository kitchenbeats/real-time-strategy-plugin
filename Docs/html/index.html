Real-Time Strategy Documentation

Welcome. This plugin gives you a complete, playable RTS in the style of StarCraft and Brood War, and the tools to turn it into your own game in Blueprint, C++ or both. Follow the five steps below in order; each builds on the one before.

Learning path

1. Install and play the starter game

  • Getting Started — install from Fab, enable the plugin, install the starter game, play a match, and make your first change.
  • What's Supported — engine version, platforms, what is included and what support covers.

2. Make it your game with the Content Set

  • The Content Set — the one asset that defines your units, buildings, resources, factions and match setup; Generate Game, Play and Check for Problems.
  • Starter Game and Generated Content — the starter game's map and rules, what Generate creates, and command-line generation.
  • Vendor-Neutral Skeletal Animation — bring your own animated characters.
  • Tech Tree — requirements, upgrade levels and tiers, set up as data.
  • Starter Audio — replace the game's sounds.

3. Add Blueprint logic with Custom Blueprints

  • Blueprint Quick Reference — where logic goes, and the events and nodes for deaths, training, selection, resources, orders and the match result.
  • UI Data API — build or restyle the HUD and bind it to game data.
  • Blueprint and C++ Examples — small working examples of every kind of extension.
  • Blueprint API Rules — how nodes report success, failure and server-only actions.

4. Extend with C++

  • Extending with C++ — module setup, where your code goes, binding events and replacing units with your own classes.
  • C++ Extension Rules — threading, server authority and object lifetime rules for your code.
  • C++ API Surface — the supported headers, by area.

5. Ship it: packaging and multiplayer

  • Packaging and Multiplayer — package your game, set up Mac networking, and test local network and dedicated-server play.
  • Dedicated Server Lobbies — run a server-managed lobby.
  • Troubleshooting — fixes for the problems people hit most often.

Reference

Gameplay systems

  • Economy and Gathering — resources, gathering, carrying and drop-off, and how to customize them.
  • Construction and Production — building placement, builders, training queues, costs, refunds and rally points.
  • Combat and Networking — health, attacks, abilities, stances and research, and how they replicate.
  • Orders — how commands work, targeting, and writing your own orders.
  • Technology Progression — research and upgrade state during a match.
  • Ownership and Teams — who owns each unit, teams and alliances.
  • Player Advantages — per-player handicaps and bonuses.
  • Gameplay Tags — gameplay tags on units and buildings.
  • Vision — sight, fog of war and remembered buildings.
  • Navigation and Flow Fields — unit movement and navigation options.
  • AI and Match Policies — AI strategy, scouting, squads and win conditions.
  • Match State — match results and eliminations.

Multiplayer

  • Network Security — what each client can see, and what the server checks.
  • Chat — in-match chat and how to skin it.
  • Team Pings — map pings between allies.

Animation and diagnostics

  • Locomotion Polish — improve walking and running for close-up quality.
  • Diagnostics — debug overlays, event logs and automated match checks.

Versions and updates
